# Bryan Mowrey Portfolio

Source for [bmowville.github.io](https://bmowville.github.io/), a lightweight portfolio for selected data, analytics, backend, and full-stack projects.

## Technical profile

- Semantic HTML with structured metadata
- Responsive CSS without a framework or runtime dependency
- Accessible navigation, visible focus states, and reduced-motion support
- Static deployment through GitHub Pages

## Local preview

From the repository root:

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.
